## Installation und Updates

Installiere zuerst Streamall für dein Gerät. Die App prüft beim Start, ob es eine neuere Version gibt. Windows startet den Installer, Android und Android TV verwenden den Systemdialog. Auf Enigma2 wird das Update über die App angeboten.

Das optionale Portalpaket hat einen eigenen Update-Kanal. Auf Enigma2 wird es als separates IPK installiert. Bei App-Versionen mit dem Menüpunkt **Portale** findest du die Installation und Aktualisierung dort.

Hier liegen die Beschreibung und die fertigen App-Pakete. Entwicklung und Builds laufen im internen Repository.
