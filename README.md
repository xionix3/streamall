## Installation und Updates

Installiere zuerst Streamall für dein Gerät. Die App prüft beim Start, ob es eine neuere Version gibt. Windows startet den Installer, Android und Android TV verwenden den Systemdialog. Auf Enigma2 wird das Update über die App angeboten. Linux öffnet den Systeminstaller. Für die Wiedergabe unter Linux wird libmpv benötigt. Für das Linux-Portalpaket wird Python 3.11 bis 3.15 benötigt.

Das optionale Portalpaket hat einen eigenen Update-Kanal. Auf Enigma2 wird es als separates IPK installiert. In Android und Desktop findest du es oben beim **S → Portale verwalten**.

Hier liegen die Beschreibung und die fertigen App-Pakete. Entwicklung und Builds laufen im internen Repository.
